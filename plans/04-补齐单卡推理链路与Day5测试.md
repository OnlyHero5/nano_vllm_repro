# 04. 补齐单卡推理主循环和 Day5 测试

这一篇只做单卡主循环。

目标是：

> 把 `Scheduler -> ModelRunner -> Sampler -> Scheduler.postprocess -> LLMEngine.generate` 这条链路整理清楚。

改完后要达到这些结果：

1. `ModelRunner` 能从 `Sequence` 里取出 `temperature / top_k / top_p`。
2. `ModelRunner.run_model()` 单独负责模型前向和 logits 计算。
3. `ModelRunner.run()` 只负责准备输入、调用模型、采样、清理 `Context`。
4. `Scheduler.postprocess()` 更新 `num_cached_tokens`。
5. `LLMEngine.step()` 的 token 统计更准确。
6. 新增 `tests/test_Day5.py`，不用大模型也能测主循环边界。

## 2. 当前代码是什么状态

当前主要问题：

1. `ModelRunner.run()` 直接调用 `self.model(input_ids, positions)`，默认模型返回 logits。
2. 采样时只构造 `temperatures`，没有 `top_k / top_p`。
3. `run()` 同时管输入准备、模型前向、取最后 logits、采样，职责太挤。
4. `run()` 结束后没有强制 `reset_context()`。
5. `Scheduler.postprocess()` 只 append token，没有更新 `num_cached_tokens`。
6. `LLMEngine.step()` 的 prefill token 统计会把历史 token 也算进去。

### 3.2 新增 `prepare_sampling_tensors()`

放在 `prepare_decode()` 后面、`run()` 前面。

```python
def prepare_sampling_tensors(
    self,
    sequences: list[Sequence],
) -> tuple[torch.Tensor, torch.Tensor, torch.Tensor]:
    """
    把每条 Sequence 的采样配置整理成张量。

    为什么从 Sequence 取：
    请求进入系统后，运行时只应该关心 Sequence 的当前状态，
    不应该再回头找用户最初传入的 SamplingParams。
    """
    temperatures = torch.tensor(
        [seq.temperature for seq in sequences],
        dtype=torch.float32,
        device=self.device,
    )
    top_ks = torch.tensor(
        [seq.top_k for seq in sequences],
        dtype=torch.long,
        device=self.device,
    )
    top_ps = torch.tensor(
        [seq.top_p for seq in sequences],
        dtype=torch.float32,
        device=self.device,
    )
    return temperatures, top_ks, top_ps
```

### 3.3 新增 `run_model()`

`run_model()` 只管模型和 logits，不管采样。

```python
@torch.inference_mode()
def run_model(
    self,
    input_ids: torch.Tensor,
    positions: torch.Tensor,
    is_prefill: bool,
) -> torch.Tensor:
    """
    执行模型主干，并返回 sampler 需要的 logits。

    前置条件：
    - self.model(input_ids, positions) 返回 hidden states。
    - self.model.compute_logits(hidden_states) 返回 vocab logits。
    """
    hidden_states = self.model(input_ids, positions)
    logits = self.model.compute_logits(hidden_states)

    if is_prefill:
        # Prefill 一次会处理整段 prompt。
        # sampler 只需要每条序列最后一个 token 的 logits。
        context = get_context()
        last_token_indices = context.cu_seqlens_q[1:] - 1
        logits = logits[last_token_indices.long()]

    # Decode 阶段本来就是每条序列只输入一个 token，
    # 所以 logits 已经是 [num_seqs, vocab_size]。
    return logits
```

### 3.4 替换 `run()`

`run()` 现在只串流程：

```python
@torch.inference_mode()
def run(
    self,
    sequences: list[Sequence],
    is_prefill: bool,
) -> list[int]:
    """
    执行当前 step，并返回每条序列的新 token。

    这里不要塞太多逻辑。
    输入准备、模型前向、采样、Context 清理分别交给明确的函数。
    """
    if not sequences:
        return []

    if is_prefill:
        input_ids, positions = self.prepare_prefill(sequences)
    else:
        input_ids, positions = self.prepare_decode(sequences)

    temperatures, top_ks, top_ps = self.prepare_sampling_tensors(sequences)

    try:
        logits = self.run_model(input_ids, positions, is_prefill)
        next_tokens = self.sampler(logits, temperatures, top_ks, top_ps)
        return next_tokens.tolist()
    finally:
        # Context 是当前 step 的临时元数据。
        # 不管本轮成功还是报错，都要清理，避免污染下一轮。
        reset_context()
```

## 4. 修改 `Scheduler.postprocess()`

建议把签名改成：

```python
def postprocess(
    self,
    seqs: List[Sequence],
    token_ids: List[int],
    is_prefill: bool,
) -> List[Sequence]:
```

完整逻辑：

```python
def postprocess(
    self,
    seqs: List[Sequence],
    token_ids: List[int],
    is_prefill: bool,
) -> List[Sequence]:
    """
    更新 step 结束后的序列状态。

    这里做三件事：
    1. 更新已经进入 KV Cache 的 token 账本。
    2. 把新生成 token 追加到序列尾部。
    3. 判断序列是否结束，结束就释放 block。
    """
    finished_seqs: List[Sequence] = []

    for seq, token_id in zip(seqs, token_ids):
        # 本轮进入模型的旧 token，在 step 结束时应该视为已经缓存。
        #
        # Prefill:
        #   prompt token 已经写入 cache。
        #
        # Decode:
        #   append_token 还没执行，所以这里的 seq.num_tokens 仍是旧长度。
        seq.num_cached_tokens = max(seq.num_cached_tokens, seq.num_tokens)

        seq.append_token(token_id)

        is_eos = (not seq.ignore_eos) and (token_id == self.eos)
        is_max_tokens = seq.num_completion_tokens >= seq.max_tokens

        if is_eos or is_max_tokens:
            seq.status = SequenceStatus.FINISHED
            self.block_manager.deallocate(seq)
            self.running.remove(seq)
            finished_seqs.append(seq)

    return finished_seqs
```

`is_prefill` 当前没有分支使用，但保留它有两个好处：

1. 调用者语义更清楚。
2. 后面如果 prefill / decode 账本规则分开，不用再改签名。

## 5. 修改 `LLMEngine.step()`

`step()` 要先统计本轮真正计算了多少 token，再跑模型。

```python
def step(self) -> tuple[list[tuple[int, list[int]]], int]:
    """
    执行一次调度和推理。

    num_tokens 的约定：
    - prefill 阶段返回正数，表示本轮新计算的 prompt token 数。
    - decode 阶段返回负数，绝对值表示本轮处理了多少条序列。
    """
    seqs, is_prefill = self.scheduler.schedule()
    if not seqs:
        return [], 0

    if is_prefill:
        # 只统计本轮新算的 token。
        # 已经命中缓存的 prefix token 不应该重复计入吞吐。
        num_tokens = sum(len(seq) - seq.num_cached_tokens for seq in seqs)
    else:
        num_tokens = -len(seqs)

    token_ids = self.model_runner.run(seqs, is_prefill)
    finished_seqs = self.scheduler.postprocess(seqs, token_ids, is_prefill)

    outputs = [
        (seq.seq_id, seq.completion_token_ids)
        for seq in finished_seqs
    ]
    return outputs, num_tokens
```

## 6. 简化 `example.py`

`example.py` 应该像一个真实可运行入口，不要只当 import smoke test。

建议要点：

1. 明确模型路径。
2. 显式构造 `SamplingParams`。
3. 打印 `generate()` 的返回结构。

示例：

```python
import os
import sys

os.environ["TOKENIZERS_PARALLELISM"] = "false"
sys.path.insert(0, os.path.dirname(os.path.abspath(__file__)))

from llm import LLM
from sampling_params import SamplingParams


def main() -> None:
    model_path = os.path.join(os.path.dirname(__file__), "models/Qwen3-0.6B")

    llm = LLM(model_path)
    sampling_params = SamplingParams(
        temperature=0.7,
        top_k=20,
        top_p=0.95,
        max_tokens=64,
    )

    prompts = [
        "你好，请用一句话解释 PagedAttention。",
        "你好，请用一句话解释 Continuous Batching。",
    ]

    outputs = llm.generate(prompts, sampling_params)

    for prompt, output in zip(prompts, outputs):
        print(f"\n[Prompt] {prompt}")
        print(f"[Text] {output['text']}")
        print(f"[Token IDs] {output['token_ids']}")


if __name__ == "__main__":
    main()
```

## 7. 新增 `tests/test_Day5.py`

这份测试不要跑大模型。它只锁主循环的结构。

```python
"""Day5 单卡推理链路测试。"""

import sys
sys.path.insert(0, ".")

import torch

from sampling_params import SamplingParams
from engine.sequence import Sequence, SequenceStatus


def test_sampling_params_are_copied_to_sequence():
    seq = Sequence(
        [1, 2, 3],
        SamplingParams(temperature=0.7, top_k=8, top_p=0.9, max_tokens=16),
    )

    assert seq.temperature == 0.7
    assert seq.top_k == 8
    assert seq.top_p == 0.9
    assert seq.max_tokens == 16


def test_model_runner_prepare_sampling_tensors():
    from engine.model_runner import ModelRunner

    # 不调用 __init__，避免加载真实模型。
    runner = ModelRunner.__new__(ModelRunner)
    runner.device = torch.device("cpu")

    seqs = [
        Sequence([1, 2], SamplingParams(temperature=0.0, top_k=0, top_p=1.0)),
        Sequence([3, 4], SamplingParams(temperature=0.8, top_k=16, top_p=0.95)),
    ]

    temperatures, top_ks, top_ps = runner.prepare_sampling_tensors(seqs)

    assert temperatures.tolist() == [0.0, 0.8]
    assert top_ks.tolist() == [0, 16]
    assert top_ps.tolist() == [1.0, 0.95]


@torch.inference_mode()
def test_llm_engine_step_counts_only_new_prefill_tokens():
    from engine.llm_engine import LLMEngine

    engine = LLMEngine.__new__(LLMEngine)

    seq = Sequence([10, 11, 12, 13], SamplingParams())
    seq.num_cached_tokens = 2

    class FakeScheduler:
        def schedule(self):
            return [seq], True

        def postprocess(self, seqs, token_ids, is_prefill):
            assert seqs == [seq]
            assert token_ids == [42]
            assert is_prefill is True
            seq.append_token(42)
            seq.status = SequenceStatus.FINISHED
            return [seq]

    class FakeRunner:
        def run(self, seqs, is_prefill):
            assert seqs == [seq]
            assert is_prefill is True
            return [42]

    engine.scheduler = FakeScheduler()
    engine.model_runner = FakeRunner()

    outputs, num_tokens = engine.step()

    assert num_tokens == 2
    assert outputs == [(seq.seq_id, [42])]
```

## 9. 常见坑

1. **`run_model()` 又做模型又做采样**
   后面 CUDA Graph 会很难接。

2. **采样参数还在 `run()` 里临时手搓**
   容易漏掉 `top_k / top_p`。

3. **prefill 统计继续用 `len(seq)`**
   会把缓存命中的 prefix 也算进去。

4. **`postprocess()` 不更新 `num_cached_tokens`**
   Prefix Cache 和后续 preemption 账本都会乱。

5. **忘记 `reset_context()`**
   当前 step 的 Context 可能污染下一轮。

## 10. 本篇结束后你应该明白

单卡主循环要分成四层：

1. `Scheduler` 决定这一轮处理谁。
2. `ModelRunner` 准备输入并跑模型。
3. `Sampler` 选出下一个 token。
4. `Scheduler.postprocess()` 更新序列状态并释放资源。
