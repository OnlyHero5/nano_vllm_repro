# repair-plans-docs Plan

## Goal

把 `plans/` 修成一套真正能带读者从当前仓库出发、逐步讲透 vLLM 核心机制的指南文档。

## Success Criteria

1. `plans/00` 明确区分现状、目标、前置条件、阅读顺序。
2. 补上一篇专门讲 `PagedAttention / BlockManager / Prefix Cache / Continuous Batching` 的核心文档。
3. `04-07` 不再把“前几篇已经改完”的中间态伪装成当前 HEAD。
4. 文风通俗、直给，避免绕和抽象空话。
5. 代码块要么是完整替代片段，要么清楚说明锚点和替换范围。

## Phases

1. 建立工作记忆并明确改写范围。
2. 重写 `00` 总览。
3. 新增核心主线文档。
4. 重写 `04-07`。
5. 统一检查链接、文件名、术语和验收命令。

## Key Decisions

- 不大规模重命名现有文件，避免把内部链接和用户阅读路径全部打碎。
- 用插入新篇章的方式补核心知识缺口。
- 优先修正文档与当前代码状态的错位，再追求覆盖面。
